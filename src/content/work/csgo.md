A personal project was creating a set of <a href="https://blog.counter-strike.net/layouts" target="_blank"> CS:GO </a> graphics for use in tournaments. It uses the game state integration system allowing for real time data to be used in displaying information in a different or more informative way than the original hud.

![Pistol Round](/assets/work/broadcast/csgo/PistolRound.jpg)
<div align="center">Pistol round</div>

This project was a test for me to be able to push what I could do as a graphics project. I had learned all the skills individually for creating large scale graphics packages but never had put them all together.

![Control Panel](/assets/work/broadcast/csgo/ControlPanel.png)
<div align="center">Control panel</div>

My goal with this project is to make a generic sports bundle that can handle players, teams, scores, matches, etc and have plugins that can hook into the bundle and add functionality for different sports and esports.
